# MeuEspaço 🌐

Uma página de links pessoais moderna, responsiva e desenvolvida para centralizar minhas principais redes e contatos em um só lugar. Este é o meu primeiro projeto publicado no GitHub!

---

## 📋 Sobre o Projeto

O **MeuEspaço** nasceu da necessidade de criar um "ponto zero" na internet para reunir meus links profissionais, redes sociais e projetos em desenvolvimento. Mais do que uma simples página de links, o projeto foi concebido como um laboratório prático para consolidar meus conhecimentos fundamentais em desenvolvimento web frontend.

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias e ferramentas foram empregadas no desenvolvimento do projeto:

* **HTML5:** Estruturação semântica e acessível do conteúdo.
* **CSS3:** Estilização customizada, uso de Flexbox/Grid e design responsivo (Mobile First).
* **JavaScript (ES6+):** Lógica para manipulação do DOM e interatividade (alternância de temas).
* **Git & GitHub:** Controle de versão e hospedagem da aplicação via GitHub Pages.

---

## ✨ Funcionalidades

* 📱 **Layout Responsivo:** Adaptável perfeitamente a diferentes tamanhos de tela (smartphones, tablets e desktops).
* 🌓 **Alternância de Tema (Dark/Light Mode):** Botão interativo para o usuário alternar entre o modo claro e o modo escuro.
* 🔗 **Cartões de Links Rápidos:** Acesso direto a redes profissionais, portfólio e principais contatos.
* ♿ **Foco em Acessibilidade:** Estrutura pensada para navegação limpa e compatibilidade com leitores de tela.

---

## 💡 Aprendizados

Desenvolver o **MeuEspaço** foi uma experiência enriquecedora que me permitiu colocar a teoria em prática. Destaco os principais aprendizados:

* Fixação dos conceitos de semântica em **HTML5** e estruturação limpa de código.
* Domínio de técnicas modernas de **CSS3** para construção de layouts adaptáveis sem dependência de frameworks externos.
* Manipulação do **DOM** com **JavaScript** puro para criar interações dinâmicas e fluidas para o usuário.
* Compreensão prática do fluxo de trabalho com **Git** (commits, branches) e publicação de sites estáticos utilizando o **GitHub Pages**.
